# 지도 요청 제어를 위한 별도 시험

기존 여행색칠을 실행하거나 계정, 위치 기록과 MapLibre 저장소를 연결하지 않고 전송 방식부터 확인하는 작은 도구입니다. 실제 지도 타일은 사용하지 않습니다. 제품 앱에는 연결하지 않았습니다.

## 2026-10-30 재개 후 저장, 중단

iPhone 시험 앱의 시작 오류를 UIScene 화면 초기화로 수정했습니다. 실제 아이폰에서 기본 통신 11개, 완료 후 홈 화면 복귀 1개와 실제 강제 종료 후 새 프로세스 재실행 1개를 통과했습니다. 복귀 때 결과와 요청 통계가 같았고, 재실행 때는 기존의 미확정 예약 256바이트를 남긴 채 새 요청의 256바이트를 추가했습니다. 이전 실패본과 새 통과 서명 앱은 모두 로컬에 보관했습니다.

Android에는 개인용 AVD를 잘못 선택하지 않도록 전용 경로, 준비 기록, 실제 프로세스와 고정 transport를 확인하는 보호 장치를 추가했습니다. 호스트 검사 25개가 통과했으며 실제 emulator에서 이 보호 장치를 검증한 결과는 아닙니다. 기존 이미지 세 파일의 현재 해시는 지난 종료 기록과 같지만, 당시 QCOW2 전후 차이의 원인은 여전히 미확정입니다. 원본을 덮어쓰거나 삭제하지 않았습니다. 저장 공간을 고려해 새 AVD와 native 재검사는 시작하지 않았습니다.

전체 verifier도 모바일 609개, 서버 61개, 합성 서버 11개와 새 환경 보호 25개, 임시 HTTP/SQLite, 파일과 양쪽 JS/Hermes까지 통과했습니다. 사용자가 현재 부분까지 저장하고 중단하도록 요청했습니다. 소유 환경과 새 시험 앱은 정리했으며 새 재개 전에는 빌드나 기기 검사를 시작하지 않습니다.

다음은 실제 네트워크 교환별 제어와 MapLibre 연결, 독립적으로 증가량을 제한한 새 Android QA AVD 준비입니다. 현재 iOS 장부는 전달 task 단위이며 OS 수신량 상한도 증명하지 않습니다. 전체 **24/54**, P3-02 부분 완료와 G1~G4 미완료를 유지합니다.

## 2026-10-29 저장 지점

| 범위 | 결과 |
| --- | --- |
| 합성 HTTP 서버 | Node 24 검사 11개 통과. 전체 공통 verifier에도 포함 |
| Android 별도 앱 | API37 Debug 에뮬레이터에서 여섯 검사 묶음 통과 |
| iPhone 별도 앱 | 서명 빌드 통과. 시작 중 화면 초기화 오류로 종료해 통신 검사는 미실행 |
| 제품 MapLibre 경로 | 양쪽 모두 미연결, 미검증 |
| OS가 실제 받은 바이트의 상한 | 보장하지 못함 |

사용자가 현재 부분까지 저장하고 중단하도록 요청했습니다. 다음 재개 전에는 새 빌드나 기기 검사를 시작하지 않습니다. 전체 계획은 24/54이며 P3-02는 부분 완료입니다.

Android에서는 두 client가 같은 dispatcher를 쓰는 상태의 본문 수명, 앱 식별값과 인증 제거, 미지원 주소와 redirect 거절, 본문 정책, 예약과 타일 한도, 실제 시험 앱 종료와 재실행을 확인했습니다. 원래 앱에서 추적한 파일 11개와 APK, UID, 네트워크와 화면 꺼짐 설정은 같았습니다. native 인증값을 직접 읽어 비교한 결과는 아닙니다.

다만 기존 AVD의 `userdata-qemu.img.qcow2`는 크기는 같아도 해시가 달랐습니다. base userdata 이미지와 `config.ini`는 같았지만 QCOW2 변경의 원인은 확정하지 못했습니다. 원본을 덮어쓰거나 삭제하지 않았고 **전체 AVD 보존 통과로 세지 않습니다.** 다음 실행은 이 차이를 안전하게 검토하고 개인용 AVD와 다른 새 시험용 AVD를 준비한 뒤 진행합니다. `-read-only`만으로 전체 파일이 같다고 가정하지 않습니다.

iPhone에서는 새 시험 앱만 설치했습니다. 종료 기록의 첫 프레임은 `___UIApplicationEvaluateRuntimeIssueForNoSceneLifecycleAdoption_block_invoke`이며 현재 소스는 legacy AppDelegate 방식입니다. 다음은 UIScene과 SceneDelegate에 맞춰 화면 시작을 고치는 작업부터입니다. 이번 시작 실패를 전송 기능의 통과나 전송 사례 실패로 세지 않으며 대상 통신 사례는 모두 NOT RUN입니다. 새 앱은 제거했고 원래 여행색칠의 설치 정보는 같았습니다. 원래 DB, 사진과 인증 저장소는 열지 않았으므로 새로운 데이터 대조 결과로 표시하지 않습니다.
