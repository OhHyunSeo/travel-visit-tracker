# iPhone 지도 통신 시험 앱

현재는 **빌드는 되지만 시작 오류가 남은 시험 소스**입니다. 사용자의 중단 요청으로 수정과 새 실행을 멈췄습니다. 다음에는 UIScene과 SceneDelegate 화면 초기화부터 수정해야 합니다. 현재 소스를 통신 검증 완료본으로 사용하지 않습니다.

앱 ID는 `app.trippainting.maptransportqa`입니다. UIKit과 Foundation만 사용하며 MapLibre, 로그인이나 위치 기록은 연결하지 않았습니다. 서명 검사에서 원래 앱과 다른 application identifier, 공유 Keychain과 app group 없음, 위치와 백그라운드 권한 없음을 확인했습니다.

## 확인한 결과

2026-10-29 signed Debug 빌드와 정적 서명 검사는 통과했습니다. 앱은 197,870바이트였습니다. 실제 아이폰에 설치해 실행했지만 UIKit의 `NoSceneLifecycleAdoption` 구간에서 종료됐고 사용자도 즉시 닫힘을 확인했습니다. 합성 리소스 요청과 통신 결과 파일이 없어 대상 네트워크 사례는 NOT RUN입니다. 시험 앱을 제거했고 원래 여행색칠의 설치 정보는 같았습니다. 기존 앱의 데이터 저장소를 열거나 새 인증 비교를 하지는 않았습니다.

다음 재개에서는 먼저 장면 초기화를 고치고 작은 앱의 시작을 확인합니다. 그다음에만 동시 요청, 취소, 응답 거절과 재실행 검사를 진행합니다. 실패한 서명 앱과 소스 해시는 로컬 `.build/pinned-startup-failed/` 및 검사 기록에 남겨 두었습니다. 이번 생성한 DerivedData 중간 출력은 해시 대조 후 정리했습니다.

## 빌드와 시험 입력

설치된 Xcode와 자신의 서명 팀을 사용합니다. `APPLE_TEAM_ID` 환경 변수를 지정하거나 첫 인자로 팀을 전달한 뒤 `build-ios.sh`를 실행합니다. 팀 값과 프로필은 저장소에 넣지 않습니다. 출력은 Git 제외 `.build/`에 생성합니다.

시험 앱 실행 시 `QA_SERVER_ORIGIN`, `QA_RUN_ID`, `QA_STAGE`를 별도로 전달합니다. 서버 주소는 포트가 있는 사설 IPv4의 HTTP 주소만 허용합니다. `basic`은 새 run ID를 사용하며, 실제 종료와 재실행을 보는 `hold`와 `resume`만 같은 ID를 공유합니다. 기존 여행색칠을 실행하거나 그 저장소 경로를 바꿔 사용하지 않습니다.

## 코드의 범위

`TPTransport`는 이 시험 앱의 NSURLSession에만 등록하는 NSURLProtocol입니다. 모든 HTTP와 HTTPS 요청을 받아 허용한 시험 주소 외에는 거절합니다. 전역 대기열은 본문 완료나 native 취소 완료까지 최대 4개의 자리를 유지하도록 작성했습니다. 전달 세션의 캐시, 쿠키와 인증 저장소를 끄고 고정 User-Agent만 보냅니다.

본문 256바이트를 작업 시작 전에 파일 장부에 예약하고 성공, 실패 뒤에도 환급하지 않습니다. 길이 미지정, 압축, 오류, redirect와 예약보다 큰 응답을 거절하도록 작성했습니다. 파일 쓰기는 같은 폴더의 임시 파일, fsync와 rename을 사용하지만 실제 전원 종료의 내구성을 검증한 결과는 아닙니다.

이 장부는 **전달 task 단위**입니다. NSURLSession 안의 투명한 재시도마다 실행되는 강제 지점이 없으므로 실제 네트워크 교환별 타일 한도로 표시하면 안 됩니다. SDK에 받아들인 본문과 OS가 이미 받은 바이트도 다릅니다. MapLibre와의 초기화 순서, 기존 요청 변환 delegate 보존, 실제 교환별 제한과 OS 수신량 보장은 모두 남아 있습니다.
