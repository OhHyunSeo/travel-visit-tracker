# 개발 체크리스트

## 10월 31일 후속 검사 저장, 중단

실제 iPhone에서 RN 패키지의 native 요청 변환 클래스와 합성 지도 렌더, 네 타일의 최대 동시 4, 외부 타일 거절 세 검사를 마쳤습니다. JS bridge나 다섯 번째 요청 대기까지 확인한 결과는 아닙니다. Android는 제한된 32MiB 공간에서 실행 파일의 버전 확인만 통과했고 새 AVD는 부팅하지 않았습니다.

전체 verifier는 모바일 609, 서버 61, 합성 서버 19, Android 호스트 61과 Mac native 10, 양쪽 JS/Hermes까지 통과했습니다. 시험 앱·서버와 이번 중간 출력을 정리했고 사용자 요청으로 중단합니다. 다음은 [재개 순서](RESUME.md)를 따릅니다. 전체 **24/54**, P3-02 부분 완료와 G1~G4 미완료는 그대로입니다.

## 10월 31일 실제 지도 엔진 시험

별도 iPhone 앱에서 실제 MapLibre의 합성 타일 수신과 렌더 완료, 외부 타일 전송 전 거절 두 검사를 마쳤습니다. Android는 작은 32MiB 저장 공간에서 실제 용량 초과·복구와 바깥 쓰기 차단을 확인했고 도구 검사 49개가 통과했습니다. 전체 verifier도 609/61, 합성 서버 17개와 양쪽 JS/Hermes까지 통과했습니다.

실제 RN 모듈과 넓은 리소스 범위, TLS/HTTP2와 오프라인 팩, Android fresh AVD 준비는 남아 있습니다. **24/54**, P3-02 부분 완료와 G1~G4 미완료를 유지합니다. [재개 순서](RESUME.md)에서 다음 범위를 확인합니다.

## 10월 30일 후속 통신 경로와 공간 준비 확인

별도 iOS 시험 경로를 한 HTTP 송신 방식으로 바꿨고 Mac native 10개, 실제 iPhone 새 소스의 기본 11개와 강제 종료/재실행 1개가 통과했습니다. Android는 용량 제한 준비 점검과 실행 차단을 보완해 호스트 39개가 통과했습니다. 새 AVD와 native 검사는 실행하지 않았습니다.

전체 verifier 609/61, 합성 서버 11개, 당시 Android 36개와 Mac 10개, 임시 HTTP/SQLite와 양쪽 JS/Hermes가 통과했고 마지막 소스의 39개/10개도 따로 통과했습니다. 제품 MapLibre와 TLS/HTTP2, OS 수신량 상한은 남아 있어 **24/54**, P3-02 부분 완료와 G1~G4 미완료를 유지합니다. [재개 순서](RESUME.md)에 새 소스의 결과와 한계를 구분했습니다.

## 10월 30일 iPhone 오류 수정과 환경 보호 검사

별도 iPhone 시험 앱의 시작 오류를 수정했고 실제 아이폰의 기본 11개, 완료 후 홈 복귀와 강제 종료 후 재실행 2개를 통과했습니다. Android 실행 보호는 호스트 검사 25개까지 완료했습니다. 기존 이미지의 현재 해시는 이전 종료값과 같지만 과거 QCOW2 차이의 원인은 여전히 미확정입니다. 새 Android native 검사나 제품 MapLibre 통합은 실행하지 않았습니다.

전체 verifier 609/61과 합성 서버 11개, 환경 보호 25개, 임시 HTTP/SQLite와 양쪽 JS/Hermes가 통과했습니다. 사용자 요청으로 현재 부분까지 저장하고 중단하며 전체 **24/54**와 수용 미완료를 유지합니다. [시험 안내](../qa/map-transport/README.md)에 소스와 결과 범위를 남겼습니다.

## 10월 29일 별도 전송 시험 후 저장, 중단

합성 서버 11개와 전체 verifier가 통과했습니다. 제품 MapLibre를 연결하지 않은 Android 별도 앱의 여섯 통신 묶음도 통과했지만, 기존 AVD의 QCOW2 해시 차이는 미해결입니다. iPhone은 서명 빌드 뒤 화면 초기화 중 종료돼 통신 대상은 NOT RUN입니다. [시험 안내](../qa/map-transport/README.md)에 결과와 한계를 남겼습니다.

소유 환경과 시험 패키지를 정리했고 사용자 요청으로 중단했습니다. 다음은 iPhone의 UIScene 시작 오류와 Android의 안전한 AVD 분리부터입니다. 전체 **24/54**와 수용 미완료는 그대로입니다.

## 10월 29일 배경지도 사전 계산과 요청 경로 검토

P3-02를 시작했습니다. 현재 경계 자료에서 지역 하나와 줌을 선택해 타일 범위의 견적을 계산하고, 저장 형태의 내용을 다시 읽을 때 버전과 수량을 대조하는 공통 코드를 추가했습니다. 새 검사 50개가 통과했습니다. 이 코드는 아직 다운로드와 화면에 연결하지 않았습니다.

iOS와 Android의 확장 경로는 확인했지만 실제 수신량 제한은 미검증입니다. 기존 지도 DB를 건드리지 않도록 첫 native 시험은 별도 앱 저장 공간으로 준비합니다. [요청 제어 검토](OFFLINE_MAP_TRANSPORT.md)에 남은 조건을 적었고 전체 **24/54**, P3-02~04와 G1~G4 미완료를 유지합니다.

## 10월 28일 배경지도 공급원 선정

P3-01의 설계 결정을 마쳤습니다. OpenFreeMap 공개 서비스와 Liberty 스타일을 선정하고, 시군구 하나와 줌 8~12의 첫 범위, 무료 사용 조건과 구현 전 지킬 한도를 [선정 문서](OFFLINE_MAP_PLAN.md)에 정리했습니다. 전체 **24/54**입니다.

이번 완료는 공급원과 조건의 선정이며 실제 배경지도 다운로드 구현은 아닙니다. 현재 SDK의 타일 cap과 사후 진행률만으로 공급원 제한을 보장하지 않도록 네이티브 전송 제어를 P3-02의 선행 구현으로 남겼습니다. Android도 소스 검토만 수행했고 기기나 빌드는 실행하지 않았습니다. P3-02~04와 수용 게이트 미완료는 유지합니다.
