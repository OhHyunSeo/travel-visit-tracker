# 방문 판정 정책과 조정 기록

기준: 2026-10-12. 아래 값은 구현·회귀 검증에 사용한 **초기 보수적 정책**이다. 현장 GPS와 배터리 측정으로 최적화된 값이 아니다. 조정 시 이 문서와 `src/domain/dwell.ts`를 함께 갱신한다.

## 시간과 품질 규칙

| 항목 | 현재 값 | 선택 이유와 검증 범위 |
| --- | --- | --- |
| 방문 인정 | 연속 관측 300초 | 사용자 요구사항. 299초 미확정·300초 확정 회귀와 양쪽 가상 GPS 확인 |
| 요청 위치 간격 | 15초 | 5분 중 약 20회 관측을 요청하는 초기값. OS가 실제 간격을 보장하지 않으며 배터리 측정 후 조정 |
| 요청 이동 거리 | 0m | 같은 지역에 정지해 머무는 시간도 관측하려는 정책. OS 이벤트 전달은 별도 검증 |
| 최대 관측 공백 | 120초 | 짧은 전달 지연에는 여유를 두고, 요청 간격 8회보다 긴 누락은 연속 체류로 인정하지 않는 초기 가정 |
| 위치 최대 나이 | 120초 | 늦게 도착한 오래된 위치로 방문을 새로 인정하지 않음. 중복·역순 이벤트는 최신 후보를 지우지 않고 먼저 무시 |
| 최대 오차 | 50m | 행정구역 경계 판정의 오차를 제한하는 초기 상한. 실내·도심의 실제 오차 분포를 확인한 뒤 조정 |
| 경계 완충 | 수신 정확도 반경 | 별도 고정 반경을 부풀리지 않고 정확도 원이 경계를 넘으면 불확실 처리. Polygon·MultiPolygon·hole 경계 모두 포함 |
| 미래 시각 허용 | 30초 | 작은 장치 시각 차이를 위한 초기 여유. 그 이상 미래 위치와 장치 시각 역행은 임의 누적하지 않음 |

초기 근거는 요구사항과 보수적인 오류 방지 가정이다. 요청 간격·50m·120초를 제품의 검증된 정확도나 배터리 목표로 홍보하지 않는다.

## 세션과 저장 규칙

- 같은 지역에서 공백이 120초 이내이고 정확도 조건을 만족한 위치가 이어져야 한 세션이다. 이동 중이라도 같은 지역이면 포함한다.
- 경계 밖·팩 밖·불확실한 위치는 후보를 중단한다. 다른 지역, 이탈 후 재진입, 긴 공백 이후에는 새 UUID 세션으로 시작한다.
- 화면 타이머는 `lastObservedAt - startedAt`으로 계산한다. 관측 없는 시간에 벽시계만 늘려 방문을 인정하지 않는다.
- 확정한 세션은 이후 관측이 이어져도 방문과 outbox를 다시 만들지 않는다. 별도의 재방문 세션은 저장하지만 수집 수와 배지는 고유 지역으로 계산한다.
- 기록 끄기·foreground 수집의 background 전환·필수 권한/위치 서비스 상실은 수집 중단을 표시한다. 이미 확정한 방문·사진은 보존한다.
- 2분 이상 새 관측이 없을 때 앱 활성 상태 점검은 후보를 만료시킨다. 만료 판단은 SQLite 트랜잭션 안의 최신 행을 읽어 새 관측을 잘못 지우지 않는다.
- 시각은 UTC epoch milliseconds로 저장하고 화면에서 한국어 지역 시각으로 표시한다. 원시 GPS 경로 전체를 저장하거나 서버로 전송하지 않는다.

## 조정 이력

| 날짜 | 변경 | 근거와 한계 |
| --- | --- | --- |
| 2026-10-11 | 위 초기 값과 세션 규칙 적용 | 요구사항과 오류 방지 가정. 현장 조정 전 |
| 2026-10-11~12 | 오래된 중복 위치와 제거된 수집기 콜백을 무시 | 자동 회귀에서 후보가 잘못 삭제되거나 다시 생성되는 경로 재현. 실제 iPhone 현상의 원인으로 단정하지 않음 |
| 2026-10-12 | 앱 활성 중 권한·서비스·긴 공백 점검 추가 | 앱을 다른 상태로 전환하지 않아도 수집 중단을 반영. 새 표본과 만료의 DB 경합 회귀 포함 |

Android 가상 GPS 체류 300.986초와 301.031초, iOS 시뮬레이터 300.215초 확정은 기기 연동 증거다. 실제 iPhone은 시각 갱신·오차 약 6m 중 지도 초 정지 현상이 미해결이며 연결 가능 시 재검증한다. 실제 Android 휴대폰은 없다. 현장·장시간 잠금·8시간 배터리 검증 후 변경 이유와 새 수치를 이 표에 추가한다.

## 2026-10-12 기록 목록 표시 정리

초기 정책의 ‘별도 방문 세션 보관, 고유 지역 한 번 수집’을 유지한다. 기록 목록은 같은 regionId를 한 카드로 묶고 첫·최근 방문과 모든 연결 사진을 모은다. 개별 방문 시각과 삭제·사진 연결은 지역 상세에서 보존한다. 이번 사용자 요청은 저장된 방문을 삭제하거나 새 세션 저장을 차단하는 변경이 아니다.
